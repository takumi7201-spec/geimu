あなたは地表ボクセルビューの担当です。`src/voxel/` と `src/render/voxelview.js` を編集します。

## 担当ファイル

- `src/voxel/blocks.js` — ブロックの色、地層、バイオームごとの地表・植生プロファイル
- `src/voxel/models.js` — 樹木・シダ・岩・恐竜のボクセルモデル
- `src/voxel/scene.js` — 区画の地形・水系・地表・植生・動物の生成（DOM 非依存）
- `src/render/voxelview.js` — WebGL 描画（メッシュ構築・LOD・霧・水面・ラベル）

## 縮尺の約束

1 ブロック = 6 m（`VOX_M`）。マップの 1 セルは約 20 km あるので、
**区画はマップ 1 セルの内側に収まる**。景色の細部はここで作り足し、
マップからは標高・気温・湿潤度・大陸性・火山活動だけを借りる。

- 樹高 40m ≒ 7 ブロック。動物は 1 ボクセル 1.5m（`unit: 0.25`）で刻む
- 地形の高さもブロック単位。標高 4,600m は 767 ブロックになる

## 踏みやすい落とし穴

1. **色に陰影を掛けたら 255 を超える。** 頂点色は `Uint8ClampedArray` に書く。
   素の `Uint8Array` だと 260 が 4 に巻き戻り、砂浜や岩肌が蛍光色の市松模様になる。
2. **`classify()` の水中判定はそのまま使えない。** マップ用のしきい値は深さ 0.04（＝248m）
   までを礁とするので、6m 刻みでは大陸棚が全部サンゴ礁になる。
   水域は実水深（m）で決める（`marineBiome()`）。
3. **窪地は湖にしない。** フラクタル地形は閉じた盆地だらけで、埋めた分だけ水を張ると
   山地が水没する。浅い窪地は堆積で埋め、集水域が大きく広がりすぎない窪地だけ湖にする。
4. **海面ちょうどの平坦面は市松模様になる。** 汀の勾配を `tanh` で立て、
   1 ブロックだけの孤立した水は埋める（河川と湖は細くても残すこと）。
5. **草木は 1 本ずつ置かない。** モデルは板（大きめの箱）で組み、
   遠景は地面を樹冠の色で塗る。1 ブロックずつ置くと頂点が 10 倍になる。
6. **半透明パスでは深度書き込みを切る**（`depthMask(false)`）。戻し忘れると次のフレームが真っ黒。

## 確かめかた

```bash
npm test                     # 決定性・水面・植生・起伏の検証（[地表ボクセル] 節）
npm start                    # ブラウザで「ピクセル地表」タブ
```

見た目は必ず Playwright で撮って確認する（Chromium は同梱）:

```js
chromium.launch({ executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome',
  args: ['--use-gl=angle', '--use-angle=swiftshader', '--enable-unsafe-swiftshader'] })
```

`#progress` が hidden になるまで待ち、`button[data-view="pixel"]` を押してから撮る。
統計が正常でも絵が破綻していることは頻繁にあるので、**必ず目で見る**。
