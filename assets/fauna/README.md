# 動物のドット絵

絵を入れる道は二つある。**手軽なのはアプリ側** ―― サイドバーの「動物の絵」で
分類ごとに PNG を選べば、その場で差し替わり、その端末が憶える。
ここに置くのは、配布物そのものに絵を含めたいとき。

ここに置いた PNG を `npm run sprites` が `src/voxel/sprites.js` に畳み込む。
**ファイル名がそのまま種別のキー**なので、下の表の名前で置くこと。

- 透明の余白は取り込みのときに刈るので、絵の位置合わせは要らない
- 絵の**横幅がその種の全長**として扱われる（高さは縦横比のまま）
- 8bit の PNG なら形式は問わない（パレット・RGBA どちらも読む）
- 10 枚すべて揃っていなくてよい。無い分類は近い体つきの絵で代用する
  （`SPRITE_FALLBACK` in `src/voxel/models.js`）

差し替えたら:

```bash
npm run sprites   # PNG → src/voxel/sprites.js
npm run bundle    # 1 枚版に反映
npm test          # どの種も絵に行き着くか検める
```

| ファイル名 | 当たる分類群 | 種数 |
|---|---|---|
| `theropod.png` | 獣脚類・基盤竜盤類・ラウイスクス類・鳥類型・ドロマエオサウルス類・鳥類 | 17 |
| `plesiosaur.png` | 鰭竜類・板歯類・原鰭竜類・首長竜（プリオサウルス類）・モササウルス類・首長竜・ウミガメ類 | 7 |
| `sauropod.png` | 竜脚形類・竜脚類 | 6 |
| `pterosaur.png` | 翼竜 | 5 |
| `ichthyosaur.png` | 魚竜・硬骨魚・異常巻アンモナイト | 4 |
| `ornithopod.png` | 鳥脚類・ハドロサウルス類・堅頭竜類 | 4 |
| `ankylosaur.png` | アエトサウルス類・曲竜類 | 2 |
| `synapsid.png` | 分椎目・キノドン類 | 2 |
| `stegosaur.png` | 剣竜類 | 1 |
| `ceratopsian.png` | 角竜類 | 1 |

いま入っているのは、既存のボクセル模型を真横から正射影した**当て板**であって
最終的な絵ではない。本番の絵に差し替えること。
