# 世界はどう作られるか

生成は 6 段階で、すべて決定論的です。シードが同じなら何度でも同じ世界が再現されます。

## 1. 大陸と海盆

紀ごとに「大陸核（craton）」を楕円の影響場として置き、重ね合わせて大陸を作ります。
単一の巨大な楕円は必ず楕円に見えてしまうので、**円に近い核を複数重ねて**形を作ります。

結合は最大値ではなく p-ノルム（三乗和の立方根）です。最大値で結合すると、核どうしの
境界に直線的な稜線が残り、海岸線にも円弧の跡が出ます。

そのうえで影響場の**距離そのものをノイズでゆがめ**ます。低周波と高周波の 2 スケールで
かけることで、大陸規模のうねりと、入り江や岬のスケールの凹凸が同時に生まれます。

内陸海路や海峡は負の影響場（sea）として彫り込みます。`rx < 0.03` の細い海域には
高周波のゆがみを強くかけます。そうしないと海峡が定規で描いた楕円のままになります。

外洋には島弧と海台を撒きます。大陸から十分離れた地点だけを選び、弧を描くように
数個の小さな核を連ねます。海台は海面下にとどめ、火山島だけが海面を突き抜けます。

## 2. 標高

`land`（正なら陸、負なら海）を高さに写します。

- **陸**：`pow(land, 1.5) * 0.30`。大陸は基本的に低平で、高度は造山帯が担います
- **造山帯**：折れ線からの距離に応じて尾根ノイズを乗せます。幅もノイズで揺らして、
  一定の太さの帯にならないようにします
- **海**：大陸から離れるほど深くします。大陸棚 → 大陸斜面 → 深海平原へなめらかに落とし、
  海嶺と深海丘陵で単調さを消します
- **例外**：大陸地殻の上（`cont > 0.25`）は深海になりません。落ち込みを 18% に圧縮し、
  内海と陸棚海が浅いまま残るようにします

## 3. 気温

緯度から求め、標高で逓減させます（0.62℃/100m）。中生代は氷冠のない温室地球なので、
極でも 0℃ 前後にとどめます。ツンドラや氷床は作りません。

## 4. 降水と雨陰

行ごとに卓越風を走らせる簡易な大気モデルです。海上では気温に応じて水蒸気を蓄え、
陸上では地形の上昇分に比例して雨を落とし、そのぶん湿り気を失います。
これで**山脈の風下に雨陰**ができます。

風向は緯度で変わります（貿易風 → 偏西風 → 極東風）が、緯度で切り替えると
30 度と 60 度に一直線の縞が出ます。そこで**東風と西風の両方を走らせ、境界緯度で
なめらかに混ぜて**います。開始経度の継ぎ目を消すため、2 周ぶんを助走に使います。

降水量は地形性の外れ値が大きく、分位点正規化では中央値がつぶれます。そこで
**順位正規化（ヒストグラム平坦化）**で 0..1 に写します。

最後に、緯度による気候帯（ITCZ・亜熱帯高圧帯・中緯度低圧帯）と、
海からの距離による内陸乾燥を掛け合わせます。内陸度は「その世界で最も海から遠い場所」を
1 として正規化します。固定値だと、大陸の大きさが紀ごとに違うため乾燥帯が出ません。

## 5. 河川と湖

半解像度で計算します。

1. Priority-Flood で窪地を埋め、すべてのセルが海へ排水できる面にする
2. 埋めた量が閾値を超えたセルを湖とする
3. 標高降順に走査して流量を集積する

埋めた面は勾配がほぼ均一なので、素直に最急降下を取ると流路が走査順に沿って直線化し、
格子状の水系になります。落差が無視できるときは下流候補から擬似乱数で選んでいます。

## 6. バイオーム

水域は「水深と大陸地殻の有無」、陸上は「火山 → 高度 → 気温 → 湿潤度」の順に判定します。
被子植物林は白亜紀にしか出ません。河川と湖の近くは湿潤度を底上げします。

## 検証

`npm test` が確認するもの:

- 同一シードから同一の世界が再現されること、シードを変えれば別の世界になること
- 陸地率・平均気温が紀ごとの想定範囲にあること
- 1 種のバイオームが陸地の 35% を超えないこと、高山帯が 6% を超えないこと
- 経度 0 の継ぎ目。隣接列の差の分布と比べ、p99 の 1.5 倍を超えないこと
- 陸塊・海域・名所・河川が検出されること
