# 世界はどう作られるか

生成は 6 段階で、すべて決定論的です。シードが同じなら何度でも同じ世界が再現されます。

## 1. 大陸と海盆

紀ごとに「大陸核（craton）」を楕円の影響場として置き、重ね合わせて大陸を作ります。
単一の巨大な楕円は必ず楕円に見えてしまうので、**円に近い核を複数重ねて**形を作ります。

結合は最大値ではなく p-ノルム（三乗和の立方根）です。最大値で結合すると、核どうしの
境界に直線的な稜線が残り、海岸線にも円弧の跡が出ます。

そのうえで影響場の**距離そのものをノイズでゆがめ**ます。低周波と高周波の 2 スケールで
かけることで、大陸規模のうねりと、入り江や岬のスケールの凹凸が同時に生まれます。

内陸海路や海峡は負の影響場（sea）として彫り込みます。`rx < 0.03` の細い海域には
高周波のゆがみを強くかけます。そうしないと海峡が定規で描いた楕円のままになります。

外洋には島弧と海台を撒きます。大陸から十分離れた地点だけを選び、弧を描くように
数個の小さな核を連ねます。海台は海面下にとどめ、火山島だけが海面を突き抜けます。

## 2. 標高

`land`（正なら陸、負なら海）を高さに写します。

- **陸**：`pow(land, 1.5) * 0.30`。大陸は基本的に低平で、高度は造山帯が担います
- **造山帯**：折れ線からの距離に応じて尾根ノイズを乗せます。幅もノイズで揺らして、
  一定の太さの帯にならないようにします
- **海**：大陸から離れるほど深くします。大陸棚 → 大陸斜面 → 深海平原へなめらかに落とし、
  海嶺と深海丘陵で単調さを消します
- **例外**：大陸地殻の上（`cont > 0.25`）は深海になりません。落ち込みを 18% に圧縮し、
  内海と陸棚海が浅いまま残るようにします

## 3. 気温

緯度から求め、標高で逓減させます（0.62℃/100m）。中生代は氷冠のない温室地球なので、
極でも 0℃ 前後にとどめます。ツンドラや氷床は作りません。

## 4. 降水と雨陰

行ごとに卓越風を走らせる簡易な大気モデルです。海上では気温に応じて水蒸気を蓄え、
陸上では地形の上昇分に比例して雨を落とし、そのぶん湿り気を失います。
これで**山脈の風下に雨陰**ができます。

風向は緯度で変わります（貿易風 → 偏西風 → 極東風）が、緯度で切り替えると
30 度と 60 度に一直線の縞が出ます。そこで**東風と西風の両方を走らせ、境界緯度で
なめらかに混ぜて**います。開始経度の継ぎ目を消すため、2 周ぶんを助走に使います。

降水量は地形性の外れ値が大きく、分位点正規化では中央値がつぶれます。そこで
**順位正規化（ヒストグラム平坦化）**で 0..1 に写します。

最後に、緯度による気候帯（ITCZ・亜熱帯高圧帯・中緯度低圧帯）と、
海からの距離による内陸乾燥を掛け合わせます。内陸度は「その世界で最も海から遠い場所」を
1 として正規化します。固定値だと、大陸の大きさが紀ごとに違うため乾燥帯が出ません。

## 5. 河川と湖

半解像度で計算します。

1. Priority-Flood で窪地を埋め、すべてのセルが海へ排水できる面にする
2. 埋めた量が閾値を超えたセルを湖とする
3. 標高降順に走査して流量を集積する

埋めた面は勾配がほぼ均一なので、素直に最急降下を取ると流路が走査順に沿って直線化し、
格子状の水系になります。落差が無視できるときは下流候補から擬似乱数で選んでいます。

## 6. バイオーム

水域は「水深と大陸地殻の有無」、陸上は「火山 → 高度 → 気温 → 湿潤度」の順に判定します。
被子植物林は白亜紀にしか出ません。河川と湖の近くは湿潤度を底上げします。

## 年代軸と大陸移動

三つの紀はキーフレームです。大陸核・海路・造山帯・火成区・地域アンカーには
紀をまたいで同じプレートを指す `id` が付いていて、`timeline.js` がこれを手がかりに
任意の年代の古地理を組み立てます。

- **大陸核と海路** — id をそろえて位置と大きさを補間します。経度はラップを考慮して
  短いほうへ動かします。片方の紀にしか無いプレートは影響度 `h` を 0 から立ち上げる／
  0 へ落とすことで、分裂や衝突として見えます。
- **造山帯** — 同じ id で節点数も同じなら**折れ線ごと動かします**。高さを単純に
  混ぜると、中間年代ですべての山脈が半分の高さになってしまうためです。
  片方の紀にしか無い山脈は、下限を残して緩やかに増減させます（削剥／隆起）。
- **火成区** — 存在の重みだけを混ぜ、影響を 0 まで落として消します。
- **海水準・気温・乾燥度** — 単純な線形補間。これにより 2億3000万年前から
  9000万年前へ向けて、陸地率が 31% → 21% と単調に減っていきます（海進）。

紀そのもの（被子植物が出るかなど）は、近いほうのキーフレームから取ります。

## 3D 地球儀

`render/globe.js` は 2D と同じラスタをテクスチャに使い、経緯度グリッドを標高で
半径方向に変位させます。実スケールでは地球半径の 0.1% しかないので 0.055 倍まで
誇張し、陸は全量、海底は 0.55 倍で効かせています。

描画は 3 パス:

1. **地形**（不透明）— ラスタをアルベドに、隣接頂点の外積で作った法線でランバート
2. **海面シェル**（半透明、深度書き込みなし）— 半径 1.0 の球。標高を詰めた
   データテクスチャを読み、陸の上では `discard`。深いほど不透明にするので、
   大陸棚と内海だけ海底が透ける
3. **大気**（裏面加算合成）— 半径 1.055 の球をフレネルで縁だけ光らせる

地名と名所は WebGL では描かず、球面座標を画面へ投影して上の 2D キャンバスに描きます。
縁に近いものほど小さく薄くしないと、球の輪郭付近で潰れて読めなくなります。

## 地表ボクセル（1 ブロック 6m）

`voxel/scene.js` は、マップの 1 セル（約 20km）の**内側**に降りたときの景色を作ります。
区画は 2.3〜4.6km 四方なので、マップのセルより小さい。つまりマップの標高を拡大しても
のっぺりした斜面が出るだけで、地形にはなりません。そこで分担はこうなっています。

| マップから借りる | その場で作る |
| --- | --- |
| 基準標高、気温、湿潤度、大陸性、火山活動 | 起伏の細部、汀線、水系、地層、植生、動物 |

### 起伏

起伏の**大きさ**だけをマップから決めます。マップの傾斜（隣接セルの差）と高度から
`rough` と `mountain` を作り、

```
m  = 基準標高
m += basin * (260 + 900 * rough)     波長 4.9km（区画をまたぐ谷）
m += hills * (90  + 420 * rough)     波長 611m
m += micro * (8   + 18  * rough)     波長 153m
m += ridge * 900 * mountain²         稜線。山地だけ
```

fbm の実効振幅は ±0.3 前後なので、係数は「その 1/3 が起伏」と読みます。
稜線ノイズを平野にも乗せると、地図に無い峰が生えて 2D 地図と食い違います。

最後に `m += 26 * tanh(m / 20)` で汀の勾配を立てます。tanh は 0 で 0 なので
**汀線の位置は動かさず、傾きだけ急にできる**のが要点で、これをしないと
海面ちょうどの高さに広い平坦面が残り、陸と 1 ブロックの水が市松模様に混ざります。

### 水系

区画の高さマップに対して、`hydrology.js` をそのまま半解像度で回します。
外周を「海」に置き換えてから流すので、水は四辺のどこへでも抜けられます。

窪地の扱いが肝心です。フラクタル地形は閉じた盆地だらけで、埋めた分だけ水を張ると
山地の 3 割が水没します。そこで窪地を連結成分にまとめ、

- 深さ 6 ブロック以上たまり、区画の 1.8% より狭く、水が集まる（流量上位 15%）→ **湖**
- それ以外 → **堆積で埋まった平地**（地面を上げる）
- 乾燥地（平均湿潤度 0.3 未満）→ 湖にしない（干上がった盆地）

### 環境と地層

バイオームはマップの値をそのまま使わず、その柱の標高・気温（6.2℃/km で逓減）・
湿潤度を `classify()` に通し直します。尾根は高地、谷底は沼、汀は砂浜になります。
ただし水域だけは別で、`classify()` のしきい値（深さ 0.04 ＝ 248m まで礁）は
20km セル向けなので、地表では実水深で分けます（4m 未満は潟、32m まで礁、110m まで陸棚）。

崖に出る地層は**高度だけの関数**です。列ごとにハッシュを混ぜると縞が横につながらず、
ただのノイズになります。

### 描き方

全ボクセルは持ちません。列の高さ 1 枚から「天面」と「隣より高い分の側面」だけを
面にします。側面は同じ岩相が続くぶんを 1 枚にまとめ、深部は 96 ブロックで打ち切ります。

遠景は中心 `cols` 四方の外で 2 倍・4 倍のブロックにまとめ（LOD）、
草木を置かない距離では地面そのものを樹冠の色で塗って森に見せます。
草木を 1 本ずつ置くと頂点が 10 倍になり、広さと引き換えに動かなくなります。

ドット絵らしさは 3 つで作ります。面ごとに単色（頂点色に陰影を焼き込む）、
内部解像度を 1/2〜1/4 に落として nearest 拡大、光源と色数を動かさないこと。
なお陰影を掛けた色は 255 を超えるので、頂点色は `Uint8ClampedArray` に書きます
（素の `Uint8Array` では 260 が 4 に巻き戻り、砂浜が蛍光色になります）。

## 検証

`npm test` が確認するもの:

- 同一シードから同一の世界が再現されること、シードを変えれば別の世界になること
- 陸地率・平均気温が紀ごとの想定範囲にあること
- 1 種のバイオームが陸地の 35% を超えないこと、高山帯が 6% を超えないこと
- 経度 0 の継ぎ目。隣接列の差の分布と比べ、p99 の 1.5 倍を超えないこと
- 陸塊・海域・名所・河川が検出されること
- プレート id が紀のなかで一意であること
- 10Ma 刻みで補間したときプレートが飛ばずに動くこと
- 中間年代でも最高峰が 3000m を下回らないこと（造山帯の補間が潰れていない）
- 時代とともに陸地率が減ること（海進の傾向）
- 地表ボクセル：同じ地点から同じ区画が組み上がること、標高差が 25m〜6km に収まること、
  区画が全面水没しないこと、水面が地面に埋まらないこと、陸生の草木が水没しないこと、
  動物が地面に埋まらないこと、河川か湖が生じること
